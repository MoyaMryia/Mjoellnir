# Personal Agent 调研报告（反方优先版）

## 结论
**no-go**：不做面向大众的独立 Personal Agent 产品/平台。理由不是执行差，而是四条结构性风险同时成立。唯一存活形态是挂在既有分发上的窄场景组件；翻转条件见 §4。

## 1. 背景与现状

**时间线**（未特别标注者为厂商官方博客/新闻稿）
- 2022-11 ChatGPT 发布，助手从"语音转文本"对话起步。
- 2023-11 OpenAI 推出 GPTs（自定义助手）。
- 2023-11 Humane AI Pin、2024-01 Rabbit R1：硬件"新入口"叙事起点；2025-02 Humane 被 HP 收购并停服（来源：HP 新闻稿）→ 单机形态证伪。
- 2024-05 Google Project Astra；2024-06 Apple Intelligence；Siri 大改据报延期至 2026（来源：Bloomberg，最终时间[推测]）。
- 2024-10 Anthropic Computer Use；2024-11 MCP 开源（来源：Anthropic）。
- 2025-01 OpenAI Operator；2025-07 ChatGPT Agent；Claude Code 转 GA（来源：Anthropic）。
- 中国：夸克"AI 超级框"、豆包/Coze、元宝+ima、小米超级小爱、华为小艺，均绑自有入口（来源：各厂发布会/产品页）。

**四类玩家**：① OS/终端（Apple、Google、微软、华为/小米/荣耀）掌握默认入口与系统权限；② 超级 App（微信/QQ、抖音、夸克）掌握高频场景与账号；③ 模型厂（OpenAI、Anthropic、Google、字节）能力即产品；④ 独立创业（Rabbit、Limitless、Mem0/Letta）做形态或记忆中间件。

**阶段判断**：能力已可用，入口与信任未定型；竞争焦点从"能不能做"转到"谁被默认调用"（推测）。

## 2. 反方最强理由：为什么不该做

**R1 分发被平台锁定**。助手价值 = 调用频率 × 权限深度，两者都来自入口。iOS/Android 把默认助理、通知、屏幕理解留给自家，微信把消息与支付留给自家；第三方只能在应用层"点一下才跑"，无法常驻、无法读屏。Humane 关停、Rabbit 口碑受损，就是自造入口的代价（来源：HP 新闻稿；媒体评测）。

**R2 数据合规成本非线性**。要"懂你"必须持续读邮件、日历、文件、浏览记录，即 PIPL/GDPR 下的敏感个人信息。合规成本随用户数近似线性上升，一次泄露即可毁品牌；企业客户常把数据流向当作一票否决项（推测）。

**R3 留存与切换成本双低**。助手是"用着好但无所谓"的品类：默认入口一换，用户零成本迁移。跨助手记忆尚无标准，MCP 等开放协议反而降低迁移成本（来源：Anthropic）。没有数据资产沉淀 = 没有 lock-in。

**R4 护城河被模型外溢蒸发**。过去需工程量身实现的"读文件、调 API、跑多步"，现在一次模型升级即被内建（Operator→ChatGPT Agent→各家 Agent 模式，来源：官方博客）。功能护城河半衰期 6–12 个月（推测）：做得好的被上游免费收编，做不好的没人要。

## 3. 逐条检验：go 还有存活空间吗

- R1：若自有 App 已是日活过亿的高频场景，或与终端厂签到默认/预装位，R1 失效。
- R2：若只做端侧推理 + 本地存储、数据不出端，合规角色从"处理者"降为"工具提供者"，成本可控（推测）。
- R3：若沉淀可迁移不了的资产（长期知识库、自动化工件、审批历史），切换成本才存在。
- R4：若护城河不在功能而在"数据闭环 + 场景独占接口"（如独占某校课表、某企业 OA），上游收编不了。

至少 R1、R4 以我们的资源无法翻盘 → 整体仍 no-go；反过来，对已有分发方是天然 go。

## 4. 翻转条件（可证伪）
任一成立即重估为 go：
- **F1 默认入口**：自有 App DAU ≥5000 万且日均助手调用场景 ≥3 次，或与 ≥2 家终端厂签默认/预装协议。
- **F2 端侧达标**：30B 级模型在目标机型 ≥20 tok/s、单机成本增量 ≤$5，使"数据不出端"可商用。
- **F3 留存达标**：运营 ≥3 个月后 W4 留存 ≥30%，且记忆类功能使用占比 ≥40%。
- **F4 上游停止收编**：12 个月内头部厂未把我们的核心场景内建为默认能力（观察项，非我方可控）。
- **止损线**：6 个月内 F1/F2 任一无进展，永久关闭。

## 5. 如果翻转，怎么做

**切入**：不做通用助手，做"高频场景 + 系统入口"的纵向切片（如论文/资料精读 + 本地知识库 + 定时执行，即本 lab 场景）。
**技术路线**：MCP 式工具协议 + 每会话常驻 Agent 进程 + 审批闸门（危险动作人工确认、内容哈希绑定、单次消费、过期失效）+ 本地向量/笔记库 + provider 抽象层（模型可换）。
**护城河**：① 个人数据资产（知识库、审批史、自动化脚本）② 场景接口独占 ③ 端侧隐私承诺——三者都不依赖模型能力。
**成本**（推测，单价按 2025 年公开 API）：10 万 DAU、每人日均 3 次 × 5k token，若 70% 走端侧、30% 走云，年云成本约 $150k–$400k；8–12 人团队年人力约 ¥1500 万–2500 万。相比"把功能做成大 App 内插件"的更优替代，独立做 ROI 更差——这正是 no-go 的量化依据。

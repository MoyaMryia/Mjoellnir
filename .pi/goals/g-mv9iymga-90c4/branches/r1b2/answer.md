## 二、背景与现状：从锚点倒推的四个阶段

- **入口年（2023-11→2024-05）**：赌「新硬件是 agent 的家」。两个标志产品都未证明留存（推测），败因是要求用户换设备。
- **上下文年（2024-05→2025-01）**：胜负手从入口变成「谁已经握着你的屏幕/文件/日历」。赢家是不需要新权限的在位者：微软、苹果、Google。
- **执行年（2025-01→）**：「能点、能跑」成为模型厂商标配（Operator、computer use），工具接入被 MCP / Apps 类协议标准化（协议细节未核实）。
- **问责年（推测）**：瓶颈从能力转为「谁为错误操作负责」，这决定独立产品能否收费。

玩家格局：价值链三层——模型/平台层（OpenAI、Anthropic、Google、微软、苹果）、终端分发层（PC/手机/浏览器默认位）、垂直执行层（coding、客服、数据）。**不存在中立的「通用 Personal Agent」独立层**：它无模型、无分发，数据接口由在位者授予且可被单方面收紧（推测）。

## 三、决策：对「独立通用 Personal Agent」**NO-GO**

最强反方：个人数据散落各 SaaS，只有中立第三方能整合，这是天然创业机会。回应：整合价值真实，但接口是租来的（可撤销，参照平台 API 收紧先例，具体条款未核实），天花板是渠道费而非平台倍数；且三个锚点显示每一跳的赢家都是「不要求用户换设备、换账号」的一方。

**GO 的唯一边界**（不是折中，是有边界条件）：若结合我方既有的终端 / 账号 / 分发位，只做单一场景 vertical agent（第四节）；否则不做。

翻转条件（全部可观测）：
- F1 2026-Q2 前，MCP 类上下文协议由 ≥3 家互不隶属的平台共管、无单一否决权，且已有第三方靠它独立变现 → 中立层成立 → 转 GO。
- F2 出现独立 agent 产品：4 周留存 >25%、ARR >5000 万美元、无预装捆绑 → 分销非决定性 → 转 GO。
- F3 监管强制 OS 开放「默认 agent」选择权（类似 DMA 浏览器选择屏）→ 分销壁垒被拆 → 转 GO。
- F4（加固 no-go）2026-06 三大平台把 agent 作为免费系统功能且不开放第三方写入 API → 窗口永久关闭 → 转做「卖铲子」。

## 四、如果做

**切入**：不做跨邮件/日历/支付的通用助手；做「把本机重复操作固化为可审计、可回滚的 skill」，先服务开发者/研究者在自己仓库与文件上的任务。理由：读自有文件不需第三方授权，规避分发与合规双重风险（推测）。

**技术路线**（不自研基座模型，只做 harness）：多供应商调用前沿模型，避免单点涨价（定价未核实）；记忆用本地 Markdown/SQLite 而非云端向量库，可读、可删、可审计；执行默认只读，写入限 git 分支/沙箱，用 git 充当 undo，权限默认 deny + 显式授权；自建 100–200 条真实任务评测（成功率/步数/人工接管率），公开部分结果。

**护城河**：①真实任务 trace 与评测集飞轮；②「数据不出本机」的信任资产；③高危操作的权限与回滚模型——在位者更怕 liability，短期不愿做（推测）。

**成本（估算，非引用）**：5 人 × 6 个月约 250–350 万元人力；推理 + 评测 30–80 万元；合规约 20 万元。单次多步任务约 0.1–0.6 美元（按 5–20 万 token、$1–3/M 输入估算）。对比：通用跨 app agent 需 30 人 × 2 年，且要拿到终端权限与法务兜底，估算 ≥8000 万元，而分发位不在我方 → 因此不做。

**验证门槛**：3 个月内上线单场景版本，4 周留存 ≥20%；不达标即停，回到 F 条件观望。

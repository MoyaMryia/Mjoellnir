# 预注册 rubric（事前写死，禁止看完结果再改）

盲评时**隐藏 effort 标签、随机顺序**，由独立 judge 按下列维度打分。
每条 0–5 分，下注权重。总分 = Σ(score × weight)。

| # | 维度 | 权重 | 5 分长什么样 |
|---|---|---|---|
| D1 | **明确决策** | 3 | 给出清晰的 go 或 no-go，并写出让它翻转的具体条件；不是"看情况/两者都行" |
| D2 | **论证依据** | 3 | 关键论断都落在具体产品、数据、机制或来源上，而非空话 |
| D3 | **反方 / 风险** | 2 | 主动给出"不值得做"的最强理由，并正面回应它 |
| D4 | **怎么做** | 2 | 若做：具体到切入场景、技术路线、护城河、成本，可执行而非口号 |
| D5 | **事实 vs 推测** | 2 | 明确区分已核实事实与推测；外部事实有来源或标注 |
| D6 | **约束遵守** | 1 | 中文、≤3000 字、只交付 report.md |

## 盲评协议

1. 两臂：`direct` vs `tree`，同模型、同约束、同 checks。
2. 产出两份 `report.md`，**去掉所有 effort 痕迹**，随机顺序记为 A/B。
3. 独立 judge（fresh 上下文）按上表打分，必须给出**具体依据**（引用报告原文）。
4. 同时记录：耗时、token、turns。
5. 结论必须能回答：**多花的算力买到了什么？** 若 tree 没赢，如实记录。

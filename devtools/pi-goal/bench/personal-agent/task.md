# 任务：Personal Agent 背景调研（§2.3 对照靶子）

假设你是某大厂产品经理的调研助手。请调研 **Personal Agent（个人智能体）** 方向，
产出一份报告 `report.md`，必须回答三件事：

1. **背景与现状**：这个方向现在到了什么阶段？主要玩家、产品、时间线。
2. **我们的决策**：值不值得做？**必须给出明确的 go / no-go**，并说明它在什么条件下会翻转、为什么。
3. **如果做，怎么做**：切入场景、产品形态、技术路线、差异化 / 护城河、成本。

## 约束

- 中文，**≤ 3000 字**。
- 每条**外部事实**必须标注来源，或显式标注为「推测 / 未核实」。
- 只有 `report.md` 是交付物；其它文件是你自己的工作区。

## 自然语言任务（直接喂给 /goal）

